# 🏠 House Price Prediction ML

Machine Learning based House Price Prediction System built using Gradient Boosting Regressor and Streamlit.

## 🚀 Features
- Data Cleaning
- Feature Engineering
- One Hot Encoding
- Hyperparameter Tuning
- Interactive Streamlit Dashboard

- Cross Validation Score: 76.8%

- Streamlit
